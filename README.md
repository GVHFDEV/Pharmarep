# PharmaRep

O PharmaRep é uma plataforma de CRM desenvolvida para simplificar e organizar a rotina de representantes farmacêuticos.

* **Cadastro de Clientes:** Gestão completa de contatos e informações relevantes dos médicos e estabelecimentos.
* **Dashboard de Performance:** Uma visão clara dos resultados, ajudando no acompanhamento das metas e no planejamento estratégico.
* **Controle de Estoque:** Monitoramento eficiente da disponibilidade de materiais e amostras.
* **Gestão de Visitas:** Registro ágil de interações, permitindo que o histórico de cada atendimento seja acessado rapidamente.

O PharmaRep foi construído utilizando React.
